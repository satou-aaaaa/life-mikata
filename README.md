# 見方をかえる

ライフゲームの盤を2つの見方で読んで、先を当てる1日5問の学習ゲームです。

- 遊ぶ: <https://satou-aaaaa.github.io/life-mikata/>
- 1段目「マスの見方」：★のマスは次の世代でどうなる？　次に生きているマスはいくつ？　グライダーはどちらへ？
- 2段目「設計の見方」：このまま世代が進むと、盤の全体は「すべて消える・止まった形になる・同じ形をくり返す・形を保って進む」のどれ？
- 盤は果てのない平面の一部です。盤の外は空のマスとして数えます。答えは、きまりどおりに世代を進めて確かめています。

## きまり

まわり8マスのうち生きたマスが、ちょうど3つなら生まれる。2つか3つなら生き残る。ほかは消える。
